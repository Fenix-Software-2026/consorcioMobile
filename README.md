# 🏢 ConsorcioApp Mobile

Aplicación móvil para la **gestión de inquilinos y consorcios**, desarrollada como parte del Proyecto Integrador.

---

## 📝 Descripción del Proyecto

**ConsorcioApp Mobile** es la versión móvil de **ConsorcioApp**, una plataforma diseñada para centralizar la comunicación y administración de consorcios.

El proyecto busca trasladar las funcionalidades principales del sistema a dispositivos móviles, proporcionando una interfaz adaptada a Android para facilitar el acceso a la información y la gestión de las diferentes operaciones del consorcio.

### 🎯 Objetivos

* 📱 Facilitar el acceso al sistema desde dispositivos móviles.
* 📢 Centralizar avisos y comunicaciones del consorcio.
* 📝 Facilitar la gestión y seguimiento de reclamos.
* 💰 Permitir la consulta de información relacionada con gastos.
* 🔐 Gestionar el acceso de los usuarios mediante autenticación.
* 🔄 Mantener una experiencia coherente con la plataforma web.

---

## 🚨 Problemas que Resuelve

* **Falta de seguimiento:** evita la pérdida de reclamos y pedidos.
* **Comunicación ineficiente:** centraliza avisos y contactos en un entorno organizado.
* **Falta de transparencia:** facilita el acceso a información sobre gestiones y movimientos.
* **Acceso poco práctico:** permite consultar la información del consorcio desde un dispositivo móvil.

## 🔗 Integración con el Backend

La aplicación móvil está diseñada para integrarse con el **backend de ConsorcioApp**, reutilizando los servicios y endpoints disponibles.

La comunicación entre los componentes se plantea de la siguiente manera:

```text
📱 ConsorcioApp Mobile
        │
        │ HTTP / API
        ▼
🌐 Backend
        │
        ▼
🗄️ Base de Datos
```

De esta manera, la aplicación móvil funciona como una interfaz de acceso a los servicios proporcionados por el backend del sistema.

## 🧪 Pruebas

El proyecto cuenta con una **planilla de Test Cases** utilizada para registrar y realizar el seguimiento de las pruebas correspondientes a las funcionalidades de la aplicación.

Los casos de prueba se **mantienen actualizados de acuerdo con los requerimientos del proyecto**, permitiendo verificar que las funcionalidades desarrolladas cumplan con el comportamiento esperado.

Cada prueba registra, entre otros datos:

* Identificador del caso de prueba.
* Funcionalidad evaluada.
* Datos de entrada.
* Pasos para ejecutar la prueba.
* Resultado esperado.
* Resultado obtenido.
* Estado de la prueba (**PASS / FAIL / NOT RUN**).

La planilla se actualiza a medida que evolucionan los requerimientos y las funcionalidades del proyecto.
